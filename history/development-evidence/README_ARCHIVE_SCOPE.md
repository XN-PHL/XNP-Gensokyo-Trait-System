# Development History

This directory is copied from the sanitized development-evidence records supplied with the project.

Included:

- version timeline;
- error and root-cause index;
- audit summaries;
- known issues and fixes;
- subsystem evolution records;
- per-version sanitized evidence excerpts.

Excluded deliberately:

- screenshots and image indexes;
- binary assets;
- raw or near-raw console files;
- old evidence manifests that referenced omitted files.
