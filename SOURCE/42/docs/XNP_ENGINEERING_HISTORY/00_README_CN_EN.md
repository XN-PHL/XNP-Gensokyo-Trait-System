This directory contains the sanitized engineering history through the XNP `0.5.60.7.18` runtime-test candidate, currently named `XNP MULTI-TRAIT SYNERGY｜GENSOKYO GAMEPLAY SYSTEM`. It is derived from version reports, static audits, second-pass audits, root-cause reports, and accepted runtime-result summaries.

Historical search alias: `XNP MULTI-MODE SYNERGY｜GENSOKYO GAMEPLAY SYSTEM`.

No raw console transcript, user name, local absolute path, Steam identity, save name, credential, or private third-party mod data is included. Runtime summaries are not presented as raw logs. Static verification and live-game verification remain separate. Missing evidence is labeled `SOURCE_EVIDENCE_NOT_RECOVERED` instead of being reconstructed.
