# 已知问题

## 当前仍需实机验证

1. 绿色弹幕的真实像素平滑度、闪烁状态、首帧碰撞画面和地图开关后的恢复。
2. 原生动态光在不同图形设置下的可见度、跟随与预算退化行为。
3. 多人服务器权威、分屏受控槽和角色死亡后新角色重绑。
4. 第三方 NPC/人形对象分类的兼容边界；玩家伤害路径保持关闭。
5. 黄色、紫色、绿色和红色 UI 在完整真实生命周期中的事务回读。
6. 真实碰撞、声音、结构效果与高并发性能。

## 已知设计边界

- 绿色弹幕是 Lua 管理的仿实体，不是真正 Iso 世界实体。
- 飞行视觉与动态光使用受预算控制的独立表现层；视觉失败不会授权静默伤害。
- CUSTOM 预设尊重合法用户值，迁移不会把所有旧设置强制重写为新默认。
- 公开发行候选通过静态和离线业务测试，但不等于稳定版本。
