# XNP 脱敏失败历史

本文件只保留可公开的工程结论。`验证状态` 中的“静态通过”不等于真实游戏已经通过。

## 1. 屏幕固定绘制

- **版本**：0.5.60.7.2 至 0.5.60.7.5
- **现象**：绿色弹体候选绘制路线可能固定在屏幕或随镜头漂移，不能可靠表示世界坐标。
- **用户表现**：移动角色或镜头时，弹体位置与世界运动不一致。
- **脱敏关键字**：`SCREEN_FIXED_UI`、`WORLD_COORDINATE_ANCHORED`、`CAMERA_REPROJECT_EVERY_FRAME`
- **根因**：早期可见代理依赖世界格标记；后续平滑路线的投影还曾重复扣除镜头偏移。
- **修复**：统一以浮点世界坐标为权威，每个渲染帧重新投影；投影只扣除一次当前玩家镜头偏移并应用缩放与视口偏移。
- **验证状态**：0.5.60.7.5 运行摘要确认飞行中可见与平滑；当前 0.5.60.7.15 仍需最终实机复测。
- **剩余风险**：分屏、不同缩放与镜头模式仍可能暴露平台差异。
- **关联文件**：`media/lua/client/XNP_PZ_DistanceRunner/XNP_DR_GreenSmoothVisual.lua`、`XNP_DR_GreenVisibleProxy.lua`

## 2. 方格残影与旧帧拖尾

- **版本**：0.5.60.7.2 至 0.5.60.7.4
- **现象**：格点代理更新时可能留下旧层，形成方格状残影或阶梯拖尾。
- **用户表现**：弹体经过的旧格子仍显示标记，视觉不像单个移动对象。
- **脱敏关键字**：`PREVIOUS_FRAME_TRAIL_CLEARED`、`OLD_FRAME_TRAIL`、`TRACKING_VISUAL_GRANULARITY`
- **根因**：基于整数格子的代理需要在换格时重建层；旧层清理与新层创建若不具备严格所有权，就可能留下残影。
- **修复**：重建前移除旧标记组；平滑路线改为每帧投影单个视觉身份，不保存旧帧表面。
- **验证状态**：静态审计确认旧层清理和无旧帧缓存；当前版本离线 20 弹测试无陈旧视觉记录。
- **剩余风险**：真实渲染器中的一帧延迟需实机观察。
- **关联文件**：`XNP_DR_GreenVisibleProxy.lua`、`XNP_DR_GreenSmoothVisual.lua`

## 3. 飞行不可见或仅终点闪烁

- **版本**：0.5.60.7.4
- **现象**：追踪和命中事务存在，但飞行中心与光晕没有被肉眼确认，只在终点看到冲击标记。
- **用户表现**：像是伤害直接发生在目标处，途中弹体消失。
- **脱敏关键字**：`INFLIGHT_VISIBLE_RUNTIME_PROVEN=false`、`IMPACT_RUNTIME_PROVEN=true`、`DRAW_PROOF`
- **根因**：世界到屏幕投影重复扣除镜头偏移，可能把纹理移出视口；回调次数不能代替像素可见证据。
- **修复**：0.5.60.7.5 修正投影契约，并加入最小飞行时间、绘制帧证明和诊断边界。
- **验证状态**：后续运行摘要确认 0.5.60.7.5 飞行中可见且亚格平滑。
- **剩余风险**：0.5.60.7.15 的插值重构需用户再次确认像素结果。
- **关联文件**：`XNP_DR_GreenSmoothVisual.lua`、`XNP_DR_GreenWorldOrb.lua`

## 4. 无画面伤害

- **版本**：0.5.60.7.2 至 0.5.60.7.4
- **现象**：伤害事务可能比可见冲击证明更早完成，产生“看不到技能但目标受伤”的风险。
- **用户表现**：敌人掉血或倒下，但没有可靠的飞行或爆炸画面。
- **脱敏关键字**：`GREEN_SILENT_DAMAGE_ROUTE`、`DAMAGE_BEFORE_VISIBLE_IMPACT`、`IMPACT_TRANSACTION`
- **根因**：早期可见层和伤害提交不是同一完整事务，回调成功曾被误当成可见结果。
- **修复**：冲击视觉创建、确认与保持先于伤害；创建失败时中止并退款；当前测试总线要求每次伤害都有冲击事务。
- **验证状态**：静态路径与离线 20 弹测试均为零静默伤害；真实游戏仍需确认。
- **剩余风险**：引擎可能接受绘制调用但不显示像素，因此实机截图仍是最终证据。
- **关联文件**：`XNP_DR_GreenWorldOrb.lua`、`XNP_DR_GreenSmoothVisual.lua`

## 5. 首帧冲击被终止

- **版本**：0.5.60.7.12
- **现象**：第一帧发生有效碰撞时，因为尚无飞行绘制证明，整个冲击事务被终止。
- **用户表现**：近距离释放没有正常爆炸，也可能被错误退款或取消。
- **脱敏关键字**：`INFLIGHT_DRAW_NOT_PROVEN`、`PRE_FIRST_DRAW_COLLISION`
- **根因**：缺少飞行绘制证明被当成终止条件，而不是诊断信息。
- **修复**：0.5.60.7.13 将该条件降级为诊断；先建立定时冲击记录，再执行效果，视觉创建失败才真正中止。
- **验证状态**：静态审计和阶段一首帧碰撞用例通过；真实首帧像素可见性未离线验证。
- **剩余风险**：极低帧率下的首帧呈现顺序依赖引擎。
- **关联文件**：`XNP_DR_GreenWorldOrb.lua`、`XNP_DR_GreenVisibleProxy.lua`、`XNP_DR_GreenSmoothVisual.lua`

## 6. 出生重叠立即爆炸

- **版本**：0.5.60.7.12
- **现象**：与玩家出生点已经重叠的僵尸可在飞行比例为零时触发碰撞。
- **用户表现**：双击后弹体没有飞行，立即在角色身边爆炸。
- **脱敏关键字**：`SPAWN_OVERLAP`、`FRACTION_ZERO`、`SPAWN_SAFETY`
- **根因**：发射时没有区分“已经重叠的对象”和飞行后新进入碰撞范围的对象。
- **修复**：仅记录发射瞬间重叠的活体僵尸，并在武装完成和安全距离达成前临时忽略；墙与车辆仍可立即碰撞。
- **验证状态**：0.5.60.7.13 静态门禁确认比例零爆炸不可达；阶段一生命周期测试通过。
- **剩余风险**：高延迟或拥挤场景下的真实碰撞次序需实机复测。
- **关联文件**：`XNP_DR_GreenWorldOrb.lua`

## 7. `unregisterCast` nil 异常

- **版本**：0.5.60.7.6
- **现象**：清理阶段反复出现 nil 调用，形成异常风暴。
- **用户表现**：连续施放后控制台报错增多，可能伴随卡顿和残留状态。
- **脱敏关键字**：`UNREGISTER_CAST_NIL`、`DOUBLE_CLEANUP`、`ALREADY_CLEANED`
- **根因**：旧清理代码在 Kahlua 环境调用不可靠的表函数，并缺少按 cast 身份校验的幂等保护。
- **修复**：改用内部计数和双重身份检查；统一 finally 清理，二次调用直接返回 `ALREADY_CLEANED`。
- **验证状态**：0.5.60.7.7 的 100 cast 清理模型通过，nil 路线静态不可达。
- **剩余风险**：原始运行文件未回收，旧异常次数属于冻结的用户摘要而非独立重算。
- **关联文件**：`XNP_DR_GreenWorldOrb.lua`

## 8. 多弹互相覆盖

- **版本**：0.5.60.7.5
- **现象**：新弹体会抢占并清理上一发，无法真正并发。
- **用户表现**：快速连发时前一发消失，只剩最后一发继续飞行。
- **脱敏关键字**：`NEW_CAST_PREEMPT`、`NEW_CAST_RESETS_EXISTING_CASTS`、`PER_CAST_OWNERSHIP`
- **根因**：旧状态以玩家为单一活动 cast 槽，新请求会执行 preempt。
- **修复**：改为按玩家和 cast ID 双索引；视觉、目标预留、灯光与清理都按 cast 身份拥有资源。
- **验证状态**：后续运行摘要证明旧版确有覆盖；阶段一 20 弹并发模型全部完成且各清理一次。
- **剩余风险**：高并发真实帧时间与视觉预算仍需实机测量。
- **关联文件**：`XNP_DR_GreenWorldOrb.lua`、`XNP_DR_GreenSmoothVisual.lua`、`XNP_DR_GreenWorldLight.lua`

## 9. 动态灯光不跟随或不可见

- **版本**：0.5.60.7.10 至 0.5.60.7.11
- **现象**：灯光可能停在发射格，持续施放后还可能出现渲染异常；仅调用坐标 setter 不保证空间索引更新。
- **用户表现**：绿色光留在身后，弹体移动但场景照明不跟随，或灯光完全不明显。
- **脱敏关键字**：`LIGHT_STUCK_AT_SPAWN`、`LAMPOST_REPLACE`、`LIGHT_BUDGET`
- **根因**：移动光源后没有重新注册到当前 cell；旧替换顺序还可能先移除有效灯再创建新灯。
- **修复**：跨格时创建并注册当前位置的新光源，成功后再移除旧光；按 cast 管理灯光，设置全局预算并在冲击、超时和退出时清理。
- **验证状态**：静态模型确认跟随更新、无重复与无陈旧灯；阶段一验证替换失败保留旧灯。真实场景照明未离线验证。
- **剩余风险**：原生光源可见性、不同图形设置和光预算效果依赖实机。
- **关联文件**：`XNP_DR_GreenWorldLight.lua`

## 10. 2 FPS / 2 Hz

- **版本**：0.5.60.7.14
- **现象**：绿色视觉和模拟实际读取为 2，而 UI 文案把枚举第二档描述为 30。
- **用户表现**：弹体严重跳动、闪烁或近似每半秒更新一次。
- **脱敏关键字**：`GreenVisualMaximumFPS=2`、`GreenSimulationUpdatesPerSecond=2`、`ENUM_INDEX_LEAK`
- **根因**：三档 enum 存储索引直接进入数值速率读取器，显示翻译没有执行运行时转换。
- **修复**：改为直接整数范围；旧索引 1/2/3 分别确定性迁移到合法 FPS 与 Hz。
- **验证状态**：0.5.60.7.15 Schema、迁移和阶段一测试通过；实际新世界帧率仍需实机确认。
- **剩余风险**：旧自定义存档可能保留不同合法值，需查看沙盒设置。
- **关联文件**：`media/sandbox-options.txt`、`media/lua/shared/XNP_PZ_DistanceRunner/XNP_DR_SandboxSchema.lua`、`XNP_DR_SandboxTuning.lua`

## 11. 目标速度 12 被 8 封顶

- **版本**：0.5.60.7.14
- **现象**：锁定目标速度请求为 12，但最终速度被旧虚拟硬上限 8 截断。
- **用户表现**：锁定后的加速达不到配置预期。
- **脱敏关键字**：`LOCKED_MAX_SPEED=12`、`VIRTUAL_HARD_CAP=8`、`math.min`
- **根因**：有效速度取目标速度与虚拟硬上限的较小值，两个默认值不一致。
- **修复**：新默认与非 CUSTOM 的旧默认迁移统一为 12。
- **验证状态**：静态配置和阶段一模型确认两个上限一致；真实速度体感待用户验证。
- **剩余风险**：CUSTOM 预设会尊重用户已有值，不强制改写。
- **关联文件**：`XNP_DR_GreenWorldOrb.lua`、`XNP_DR_SandboxSchema.lua`、`XNP_DR_SandboxTuning.lua`

## 12. 黄色只响音效

- **版本**：0.5.60.7.14
- **现象**：输入路线先播放音效，但状态、玩法门禁和白色 UI 没有作为一个事务完成。
- **用户表现**：点击黄色切换后能听到声音，却看不到可靠状态变化。
- **脱敏关键字**：`YELLOW_AUDIO_ONLY`、`SOUND_WITHOUT_FULL_COMMIT`、`WHITE_PERSISTS`
- **根因**：音效先于完整提交；动态颜色刷新未优先尊重手动关闭所有者，白色可能被覆盖。
- **修复**：统一由主状态所有者提交，回读玩法门禁和 UI 后才播放音效；手动关闭优先于动态颜色。
- **验证状态**：0.5.60.7.15 离线 600 帧白色保持测试通过；真实输入和 UI 仍需实机确认。
- **剩余风险**：特定 UI 生命周期事件可能影响首次刷新时机。
- **关联文件**：`XNP_DR_MasterEffectState.lua`、黄色状态与 UI 模块

## 13. 紫色 `PLAYER_WRITES_SUSPENDED`

- **版本**：0.5.60.7.14
- **现象**：一次短暂身份不匹配设置跨帧写入暂停，后续紫色事务持续被拒绝。
- **用户表现**：右键残机切换或修复反复失败，重新操作也无法恢复。
- **脱敏关键字**：`PLAYER_WRITES_SUSPENDED`、`IDENTITY_MISMATCH`、`GLOBAL_STICKY_FREEZE`
- **根因**：事务级身份失败被提升为全局持久状态，并被所有颜色系统共享。
- **修复**：当前受控玩家通过 slot 与 primary 对象相等解析；不匹配只拒绝当前事务，旧冻结键由一次性迁移清除。
- **验证状态**：0.5.60.7.15 静态和业务模型确认粘滞冻结不可达；真实游戏需确认。
- **剩余风险**：多人和角色替换时的引擎对象生命周期仍需实机覆盖。
- **关联文件**：`XNP_DR_CanonicalPlayerIdentity.lua`、`XNP_DR_ReleaseMigration.lua`

## 14. 新角色安全重绑阻断

- **版本**：0.5.60.7.13 至 0.5.60.7.14
- **现象**：旧角色死亡后的 tombstone 或身份状态可能阻止同世界合法新角色接管。
- **用户表现**：创建新角色后技能 UI 或功能不重新绑定。
- **脱敏关键字**：`POST_DEATH_SUCCESSOR`、`GLOBAL_TOMBSTONE`、`THREE_FRAME_CONFIRMATION`
- **根因**：死亡对象状态与玩家槽所有权绑定过紧，普通启动和继任者暂存还曾共享身份状态。
- **修复**：只有已 tombstone 的旧对象可开启继任流程；新活体必须连续三帧等于受控槽对象，确认后重建缓存和 UI。
- **验证状态**：离线正常启动、合法继任和 NPC 拒绝模型通过；真实死亡后建角流程待用户验证。
- **剩余风险**：分屏与多人服务器的受控槽语义尚未完整实机覆盖。
- **关联文件**：`XNP_DR_CanonicalPlayerIdentity.lua`、`XNP_DR_Bootstrap.lua`

## 15. 错误人物对象风险

- **版本**：0.5.60.7.13 及以前路线
- **现象**：事件候选对象若只按名称、ID、邻近或类别猜测，可能把 NPC、代理或旧死亡对象当成当前玩家。
- **用户表现**：技能成本、物品、状态或 UI 可能写到错误角色。
- **脱敏关键字**：`CANONICAL_PLAYER`、`EXACT_OBJECT_EQUALITY`、`NONCANONICAL_REJECT`
- **根因**：多个事件提供的 candidate 并不天然等于受控玩家，诊断身份字段不能作为写入授权。
- **修复**：要求事件对象与受控 slot 及 primary player 精确相等；名称和数字 ID 只用于诊断，NPC/未知对象失败关闭。
- **验证状态**：静态审计与离线 NPC 拒绝用例通过；第三方 NPC 环境仍需实机验证。
- **剩余风险**：引擎或第三方模组可能提供未见过的代理对象类型。
- **关联文件**：`XNP_DR_CanonicalPlayerIdentity.lua`

## 16. 0.5.60.7.14 整版运行失败

- **根因**：身份冻结、UI/状态所有权分裂、enum 索引误读和旧默认迁移问题叠加；静态可达性没有覆盖实际生命周期。
- **修复**：0.5.60.7.15 采用选择性恢复：事务级身份拒绝、单一状态所有者、子系统故障隔离、确定性迁移和离线业务总线。
- **验证状态**：当前候选静态硬门禁和离线业务测试通过，但没有把 0.5.60.7.14 的静态成功改写为运行成功。
- **剩余风险**：0.5.60.7.15 仍需完整真实游戏回归。

## 17. 0.5.60.7.15 阶段一：绿色弹幕恢复

- **版本**：0.5.60.7.15 Stage 1
- **现象**：需要同时修复插值、闪烁隔离、灯光替换、2/2 速率与 12/8 上限，而不回滚其他系统。
- **用户表现**：目标是恢复可连续观察的多弹飞行、稳定核心和跟随灯光。
- **脱敏关键字**：`20_CAST_HARNESS`、`INTERPOLATION`、`DRAW_ISOLATION`、`WORLD_LIGHT`

- **修复**：前后模拟坐标插值、稳定核心 alpha、逐 cast 保护、先建新灯后移除旧灯、30/60 直接速率与上限迁移。
- **验证状态**：20 弹离线生命周期测试通过；无陈旧 cast、灯光、双重清理或静默伤害。真实像素和场景光仍未离线验证。
- **剩余风险**：实际 FPS、镜头、地图切换和原生光源可见性。
- **关联文件**：`XNP_DR_GreenWorldOrb.lua`、`XNP_DR_GreenSmoothVisual.lua`、`XNP_DR_GreenWorldLight.lua`

## 18. 0.5.60.7.15 阶段二：红色 P 点事务

- **版本**：0.5.60.7.15 Stage 2
- **现象**：P 点公开文案、制作后的不开心增加和无聊降低需要形成可回滚的单次事务。
- **用户表现**：右键显示“使用P点”；制作成功后情绪按配置变化，失败或取消不能扣除情绪。
